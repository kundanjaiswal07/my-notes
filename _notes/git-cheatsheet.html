Git Cheatsheet

Essential git commands for daily use. The ones you Google every time — collected in one place.

The commands you actually use

Stashing

bashgit stash              # stash current changes
git stash pop          # apply most recent stash
git stash list         # see all stashes
git stash apply stash@{2}  # apply a specific stash

Undoing things

git restore .          # discard all working directory changes
git restore file.txt   # discard changes to one file
git reset HEAD~1       # undo last commit, keep changes staged
git reset --hard HEAD~1 # undo last commit, discard changes
Careful: --hard reset is destructive. Use git reflog to recover if you mess up.

Branching

git switch -c feature/my-feature   # create + switch to branch
git switch main                     # switch to main
git branch -d feature/my-feature    # delete branch (safe)
git branch -D feature/my-feature    # delete branch (force)

Rebase vs merge

CommandWhen to use
git mergePreserving full history, pull requests
git rebaseCleaner linear history on feature branches
git rebase -i HEAD~3Squash / reword last 3 commits

Useful one-liners

git log --oneline --graph --all         # visual branch history
git diff --stat HEAD~1                  # what changed in last commit
git cherry-pick abc1234                 # apply a specific commit
git bisect start                        # find which commit broke something
