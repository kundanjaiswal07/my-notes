1 Which learning approach is best suited for predicting continuous values like house prices? ▼
A) Classification
B) Regression
C) Clustering
D) Anomaly Detection
✓ Answer: B
Explanation: Regression predicts continuous numerical values. Classification predicts categories; clustering groups items; anomaly detection finds outliers.
2 A retail company wants to segment customers into groups based on purchasing behavior without predefined labels. What type of learning is this? ▼
A) Supervised Learning
B) Unsupervised Learning
C) Reinforcement Learning
D) Semi-supervised Learning
✓ Answer: B
Explanation: Unsupervised learning discovers patterns in unlabeled data. Clustering (grouping) is a common unsupervised task.
3 What is the difference between deep learning and traditional machine learning? ▼
A) Deep learning is always more accurate
B) Deep learning uses neural networks with multiple layers; traditional ML uses simpler algorithms
C) There is no difference
D) Deep learning only works with images
✓ Answer: B
Explanation: Deep learning (neural networks with many layers) can automatically learn feature hierarchies. Traditional ML often requires manual feature engineering.
4 Which of the following is an example of reinforcement learning? ▼
A) Predicting movie ratings
B) A computer playing chess and improving through trial and error
C) Classifying emails as spam or not spam
D) Clustering products by category
✓ Answer: B
Explanation: Reinforcement learning involves an agent learning by taking actions, receiving rewards/penalties, and iterating. Chess is a classic example.
5 What does "overfitting" mean in ML? ▼
A) Model accuracy is too high
B) Model learns training data too well but fails to generalize to new data
C) Model has too many features
D) Model converges too slowly
✓ Answer: B
Explanation: Overfitting occurs when a model memorizes training data instead of learning generalizable patterns, resulting in poor real-world performance.
6 Arrange these ML pipeline stages in correct order: A) Model Training, B) Data Collection, C) Evaluation, D) Data Preprocessing ▼
A) B → D → A → C
B) A → B → C → D
C) C → A → B → D
D) B → A → D → C
✓ Answer: A
Explanation: Correct order: Data Collection → Data Preprocessing → Model Training → Evaluation. This is the standard ML workflow.
7 Which AWS service is best for building a customer churn prediction model using tabular data? ▼
A) Amazon Rekognition
B) Amazon SageMaker Autopilot
C) Amazon Polly
D) Amazon Personalize
✓ Answer: B
Explanation: SageMaker Autopilot automatically builds, trains, and tunes classification and regression models on tabular data with minimal effort.
8 What is transfer learning? ▼
A) Moving a model from one AWS region to another
B) Using a pre-trained model as a starting point and fine-tuning it for a new task
C) Training a model on large data and then smaller data
D) Converting between frameworks (TensorFlow to PyTorch)
✓ Answer: B
Explanation: Transfer learning reuses knowledge from pre-trained models, accelerating training and improving performance on new tasks.
9 What is model monitoring in production? ▼
A) Watching developers code
B) Continuously checking model performance, detecting data/concept drift, and triggering retraining when needed
C) Monitoring AWS costs only
D) Not necessary for deployed models
✓ Answer: B
Explanation: Model monitoring detects performance degradation, data distribution changes, and triggers retraining or alerts. Essential for MLOps.
10 Which metric should you use to evaluate a binary classification model with imbalanced classes? ▼
A) Accuracy
B) F1 Score or Precision-Recall curve
C) R-squared
D) Silhouette Score
✓ Answer: B
Explanation: With imbalanced data, accuracy is misleading. F1 Score balances precision and recall. These are better for imbalanced classification.

1 What is a token in the context of large language models? ▼
A) A security credential for authentication
B) A unit of text (word, subword, or character) that the model processes
C) A cryptocurrency used in blockchain
D) A temporary access key
✓ Answer: B
Explanation: Tokens are the smallest units of text that LLMs process. Different models tokenize differently; "hello" might be 1 token, longer words might be 2-3.
2 What is the primary advantage of using embeddings in generative AI? ▼
A) They reduce model size by 90%
B) They convert text/images into numerical vectors that capture semantic meaning
C) They eliminate the need for training data
D) They guarantee 100% accuracy
✓ Answer: B
Explanation: Embeddings represent text/images as dense vectors capturing semantic relationships. Similar concepts have similar embeddings.
3 Which best describes a foundation model? ▼
A) A small, task-specific model trained on one dataset
B) A large-scale model pre-trained on diverse data, adaptable to many downstream tasks
C) A model that only works for classification
D) A model that requires real-time user feedback to function
✓ Answer: B
Explanation: Foundation models (Claude, GPT, Mistral) are large, pre-trained on diverse data and adaptable via fine-tuning or prompting.
4 What is prompt engineering? ▼
A) Designing hardware for AI servers
B) Crafting effective instructions/examples to guide LLM outputs toward desired behavior
C) Writing code to train neural networks
D) Configuring AWS infrastructure
✓ Answer: B
Explanation: Prompt engineering is crafting prompts to elicit high-quality, relevant responses from LLMs.
5 What is the difference between zero-shot and few-shot prompting? ▼
A) Zero-shot uses no examples; few-shot provides examples to guide the model
B) Zero-shot is always better
C) They're identical
D) Few-shot requires fine-tuning
✓ Answer: A
Explanation: Zero-shot: direct instruction without examples. Few-shot: instruction + examples (usually improves accuracy).
6 What is "chain-of-thought" prompting? ▼
A) A type of neural network layer
B) Asking the model to show reasoning steps before answering (improves accuracy for complex tasks)
C) A method for text compression
D) Not useful for LLMs
✓ Answer: B
Explanation: Chain-of-thought prompts ask models to break down reasoning, improving accuracy on complex reasoning tasks.
7 What does the "temperature" parameter control in LLM inference? ▼
A) Actual hardware temperature
B) The randomness/creativity of model outputs (higher = more random, lower = deterministic)
C) The speed of inference
D) The cost of API calls
✓ Answer: B
Explanation: Temperature (0-1) controls output randomness. Temperature 0 = deterministic; higher = more creative/varied responses.
8 What is a major limitation of current LLMs? ▼
A) They're too accurate
B) Hallucinations – generating confident-sounding but false information
C) They learn too slowly
D) They work perfectly without any training data
✓ Answer: B
Explanation: LLMs can generate confident-sounding but factually incorrect information (hallucinations). They're probabilistic, not deterministic.
9 Which AWS service provides access to multiple foundation models via a single API? ▼
A) Amazon SageMaker (training only)
B) Amazon Bedrock
C) AWS Lambda
D) Amazon EC2
✓ Answer: B
Explanation: Bedrock is AWS's managed service providing API access to foundation models from Anthropic, Meta, Mistral, and others.
10 What is multi-modal capability in foundation models? ▼
A) Speaking multiple languages
B) Processing multiple input types (text, images, documents) in a single request
C) Training multiple times
D) Supporting multiple AWS regions
✓ Answer: B
Explanation: Multi-modal models (e.g., Claude 3) can process and reason over text, images, and documents together.

1 A company's knowledge base updates daily. They want models to use current information without retraining. What approach should they use? VERY FREQ ▼
A) Fine-tune the model daily
B) Use Retrieval Augmented Generation (RAG) with a knowledge base
C) Increase the temperature parameter
D) Use only zero-shot prompting
✓ Answer: B
Explanation: RAG retrieves current documents at inference time, allowing real-time updates without retraining. Fine-tuning daily would be expensive. This is the MOST common scenario.
2 Where should a company store embeddings for vector similarity search? VERY FREQ ▼
A) Amazon S3 only
B) Amazon OpenSearch Service or Amazon Neptune
C) Amazon RDS (only text)
D) AWS Lambda
✓ Answer: B
Explanation: OpenSearch and Neptune support vector storage and k-NN search needed for semantic retrieval in RAG pipelines.
3 When is fine-tuning better than RAG or prompt engineering? FREQUENT ▼
A) Always, for everything
B) For stable behaviors/styles you want permanent (company tone, terminology)
C) Never – prompting is always better
D) Only for image models
✓ Answer: B
Explanation: Fine-tuning teaches permanent behaviors; RAG adds current facts; prompting guides interactions. Use fine-tuning for stable learnings.
4 Which metric should you use to evaluate a summarization model? FREQUENT ▼
A) Accuracy
B) ROUGE (Recall-Oriented Understudy for Gisting Evaluation)
C) Silhouette Score
D) MSE
✓ Answer: B
Explanation: ROUGE compares generated to reference summaries. Accuracy is for classification; Silhouette for clustering; MSE for regression.
5 What does BLEU measure? ▼
A) The color of outputs
B) Translation quality by comparing to reference translations
C) Binary classification accuracy
D) Server response latency
✓ Answer: B
Explanation: BLEU is the standard metric for machine translation evaluation, measuring n-gram overlap with reference translations.
6 What is "chunking" in RAG pipelines? ▼
A) Reducing model size
B) Dividing large documents into smaller semantic units for embedding and retrieval
C) Compressing data
D) Splitting development teams
✓ Answer: B
Explanation: Chunking breaks documents into manageable pieces that fit within embedding and context windows, enabling efficient retrieval.
7 A media company wants to provide natural language image search. What vector database approach works best? ▼
A) Amazon Comprehend
B) Amazon Personalize
C) Amazon OpenSearch Service with vector embeddings
D) Amazon Polly
✓ Answer: C
Explanation: OpenSearch supports k-NN search on embeddings generated from images, enabling semantic similarity search between text queries and image embeddings.
8 What is the primary trade-off between RAG and fine-tuning? ▼
A) RAG is always better
B) Fine-tuning costs money; RAG is free
C) RAG best for dynamic/current knowledge; fine-tuning for stable behaviors/styles
D) They are identical approaches
✓ Answer: C
Explanation: RAG excels at grounding models in current, external data. Fine-tuning teaches stable behaviors and terminology.
9 How should a company approach prompt engineering for production systems? ▼
A) Use a random prompt and hope it works
B) Experimentally test prompts, version them, and monitor performance
C) Write a single prompt and never change it
D) Use only complex prompts
✓ Answer: B
Explanation: Production prompts require experimentation, versioning, monitoring, and iteration for consistent, high-quality outputs.
10 Which AWS service can be used for human-in-the-loop evaluation? ▼
A) Amazon CloudWatch
B) Amazon Lex
C) Amazon SageMaker Ground Truth or Amazon A2I
D) AWS Lambda
✓ Answer: C
Explanation: Ground Truth and A2I enable human review and labeling of model outputs for evaluation and continuous improvement.

1 What is algorithmic bias? VERY FREQ ▼
A) Bias in humans only
B) Systematic unfairness where models produce different outcomes for different demographic groups
C) Having too many parameters
D) Not relevant to AI
✓ Answer: B
Explanation: Algorithmic bias occurs when models learn to systematically favor/disfavor groups due to biased training data or features.
2 Which AWS service detects and measures bias in ML models? VERY FREQ ▼
A) Amazon Lex
B) Amazon SageMaker Clarify
C) Amazon Personalize
D) Amazon Textract
✓ Answer: B
Explanation: SageMaker Clarify provides tools to detect, measure, and mitigate bias. This is almost always the answer to "bias detection" questions.
3 What is a major legal risk when using generative AI? ▼
A) No legal risks
B) Copyright infringement (output similar to training data) and IP claims
C) Too many regulations
D) Regulations don't apply to AI
✓ Answer: B
Explanation: GenAI can reproduce training data or generate copyrighted content, creating legal liability for organizations.
4 Which AWS service filters harmful content and PII from Bedrock outputs? FREQUENT ▼
A) Amazon Lex
B) Amazon Bedrock Guardrails
C) AWS Lambda
D) Amazon S3
✓ Answer: B
Explanation: Bedrock Guardrails enable topic restrictions, PII redaction, and harmful content filtering. This is almost always the answer to "content filtering" questions.
5 What are the six AWS Responsible AI principles? (Name at least 3) ▼
Answer: Any 3 of the following:
  • Fairness – equitable outcomes without systematic bias
  • Explainability – understandable decisions and reasoning
  • Privacy – data protection and user privacy
  • Robustness – reliable and resilient systems
  • Governance – documented policies and oversight
  • Transparency – clear documentation and disclosure
Explanation: AWS's responsible AI framework emphasizes equitable, interpretable, private, robust, well-governed, and transparent AI systems.

B) Documenting how data flows from sources through pipelines to models
C) Just storing data
D) Not important for governance
