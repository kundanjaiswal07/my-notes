Sample Questions

Q1: Which learning approach is best suited for predicting continuous values like house prices? ▼

A) Classification

B) Regression

C) Clustering

D) Anomaly Detection

✓ Answer: B
Explanation: Regression predicts continuous numerical values. Classification predicts categories; clustering groups items; anomaly detection finds outliers.
Q2: A retail company wants to segment customers into groups based on purchasing behavior without predefined labels. What type of learning is this? ▼

A) Supervised Learning

B) Unsupervised Learning

C) Reinforcement Learning

D) Semi-supervised Learning

✓ Answer: B
Explanation: Unsupervised learning discovers patterns in unlabeled data. Clustering (grouping) is a common unsupervised task.
Q3: Arrange these ML pipeline stages in correct order: A) Model Training, B) Data Collection, C) Evaluation, D) Data Preprocessing ▼

A) B → D → A → C

B) A → B → C → D

C) C → A → B → D

D) B → A → D → C

✓ Answer: A
Explanation: Correct order: Data Collection → Data Preprocessing → Model Training → Evaluation. This is the standard ML workflow.

🔑 Key Concepts to Master

  • Tokens: Units of text the model processes (words, subwords, characters)
  • Embeddings: Numerical vectors capturing semantic meaning
  • Foundation Models: Large pre-trained models adaptable to many tasks
  • Prompt Engineering: Crafting effective instructions for LLMs
  • Temperature: Controls randomness (0=deterministic, high=creative)
  • Hallucinations: LLMs can generate plausible but false information

Sample Questions

Q1: What is a token in the context of large language models? ▼

A) A security credential for authentication

B) A unit of text (word, subword, or character) that the model processes

C) A cryptocurrency used in blockchain

D) A temporary access key

✓ Answer: B
Explanation: Tokens are the smallest units of text that LLMs process. Different models tokenize differently; "hello" might be 1 token, while longer words might be 2-3 tokens.
Q2: What is the primary advantage of using embeddings in generative AI? ▼

A) They reduce model size by 90%

B) They convert text/images into numerical vectors that capture semantic meaning

C) They eliminate the need for training data

D) They guarantee 100% accuracy

✓ Answer: B
Explanation: Embeddings represent text or images as dense vectors in a lower-dimensional space, capturing semantic relationships. Similar concepts have similar embeddings.

🎯 Domain 3 Critical Rules

  • RAG vs Fine-tuning: Changing facts = RAG; Stable style/behavior = fine-tuning
  • RAG is best for: Current/dynamic knowledge that changes frequently
  • Fine-tuning is best for: Permanent behaviors, terminology, writing style
  • Temperature direction: Higher = more random/creative; Lower = deterministic
  • ROUGE metric: Used for summarization evaluation
  • BLEU metric: Used for translation evaluation
  • Vector databases on AWS: OpenSearch Service or Neptune

Sample Questions

Q1: A company wants its chatbot to answer questions about internal company policies that change weekly. The company doesn't want to retrain the model. What approach should they use? ▼

A) Fine-tune the model on policy documents

B) Use Retrieval Augmented Generation (RAG) with a knowledge base

C) Increase the temperature parameter

D) Use only zero-shot prompting

✓ Answer: B
Explanation: RAG retrieves current policy documents from a knowledge base at inference time, allowing real-time updates without retraining. Fine-tuning is expensive and slow for frequently changing data. This is the most common scenario on the exam.
Q2: Where should a company store embeddings for a vector similarity search in AWS? ▼

A) Amazon S3 only

B) Amazon OpenSearch Service (with vector database capability) or Amazon Neptune

C) Amazon RDS (only text)

D) AWS Lambda

✓ Answer: B
Explanation: Amazon OpenSearch Service and Amazon Neptune support vector storage and k-nearest neighbor (k-NN) search for semantic similarity searches required in RAG systems.
Q3: Which metric should you use to evaluate a summarization model? ▼

A) Accuracy

B) ROUGE (Recall-Oriented Understudy for Gisting Evaluation)

C) Silhouette Score

D) MSE

✓ Answer: B
Explanation: ROUGE compares generated summaries to reference summaries, measuring overlap and quality. Accuracy is for classification; Silhouette Score for clustering; MSE for regression.

🎯 Six AWS Responsible AI Principles

  • Fairness: Equitable outcomes without systematic bias
  • Explainability: Understandable decisions and reasoning
  • Privacy: Data protection and user privacy
  • Robustness: Reliable and resilient systems
  • Governance: Documented policies and oversight
  • Transparency: Clear documentation and disclosure

Sample Questions

Q1: A model trained on historical hiring data tends to reject women's applications. Why? ▼

A) The model is always right

B) Historical bias in training data (fewer women hired historically) → model learns biased patterns

C) Models can't be biased

D) Not a concern

✓ Answer: B
Explanation: Machine learning systems inherit and amplify biases in training data. This is a critical concept in responsible AI.
Q2: Which AWS service can detect and measure bias in ML models? ▼

A) Amazon Lex

B) Amazon SageMaker Clarify

C) Amazon Personalize

D) Amazon Textract

✓ Answer: B
Explanation: SageMaker Clarify provides tools to detect, measure, and mitigate bias before and after model deployment. This is almost always the answer to "bias detection" questions.

Sample Questions

Q1: How does AWS IAM control access to Amazon Bedrock? ▼

A) IAM doesn't apply to Bedrock

B) IAM roles and policies specify who can call Bedrock APIs and which models they can access

C) No access control needed

D) Only AWS staff can access

✓ Answer: B
Explanation: IAM is the standard AWS access control mechanism, including for Bedrock API calls and model selections. This is fundamental to AWS security.
Q2: What is a "prompt injection" attack? ▼

A) Injecting money into prompts

B) Malicious inputs designed to override model instructions or extract sensitive information

C) Injecting training data

D) Not a real threat

✓ Answer: B
Explanation: Prompt injection is a social engineering attack on LLMs where users embed malicious instructions in prompts to override model behavior or extract sensitive data.
